## Reflection

Automation is essential in cloud computing because managing hundreds of servers manually can become difficult and time-consuming. Administrators need reliable methods for performing repetitive tasks such as creating backups, monitoring systems, and maintaining files. By using scripts and scheduled tasks, they can complete routine operations consistently while spending more time on other responsibilities.

Although automation provides many advantages, it also has potential risks. An incorrectly written script can cause problems across multiple systems, especially when it is deployed without proper testing. For example, a command intended to clean temporary files might accidentally remove important data. This shows why scripts should be reviewed, tested in a safe environment, and monitored after deployment.

Creating a Bash script in this laboratory was different from writing a Docker Compose YAML file in Mission 6. A Bash script contains commands that are executed in sequence to accomplish a task. Docker Compose uses a YAML configuration to define services, containers, and their settings. Both can simplify cloud operations, but Bash is more focused on executing commands, while Docker Compose describes the desired container setup.

Reviewing the activities from Laboratories 1 through 9 helped me understand that cloud computing involves more than accessing online storage or virtual machines. Throughout the course, I learned about Linux administration, cloud infrastructure, containerization, networking, security, and automation. Each laboratory introduced a different responsibility involved in maintaining cloud-based services.

The Cloud Automation Engineer role interests me because it combines problem-solving with practical scripting skills. During this activity, I learned how a simple Bash script can create timestamped backup files and how Cron can schedule the process automatically. I found it useful to see how repetitive tasks can be organized into a reliable workflow.

Overall, this laboratory strengthened my understanding of Linux automation and reminded me that automated processes still require careful configuration, testing, and monitoring.
