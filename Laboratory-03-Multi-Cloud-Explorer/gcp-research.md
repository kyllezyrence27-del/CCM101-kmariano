# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers cloud services for computing, storage, networking, databases, data analytics, artificial intelligence, and application development.

## Global Infrastructure

Google Cloud operates through a global infrastructure composed of regions and zones. Its infrastructure is designed to provide reliable and scalable cloud resources for applications and services around the world.

## Cloud Management Console

The Google Cloud Console is a web-based management interface used to create, configure, monitor, and manage Google Cloud resources. It allows users to access cloud services and view information about their projects and resources.

## Four Core Services

1. **Compute Engine** – Provides virtual machines for running applications and workloads.
2. **Cloud Storage** – Provides scalable object storage for different types of data.
3. **Cloud SQL** – Provides managed relational database services.
4. **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes clusters for containerized applications.

## Three Advantages

1. GCP has strong capabilities in data analytics and artificial intelligence.
2. Its infrastructure supports scalable and globally distributed applications.
3. GCP provides managed services that can reduce the work required to maintain cloud infrastructure.

## Typical Enterprise Use Cases

GCP can be used for data analytics, artificial intelligence and machine learning, application hosting, containerized applications, data storage, and large-scale web services.
