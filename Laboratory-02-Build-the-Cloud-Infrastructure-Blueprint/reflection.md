# Mission Reflection

This laboratory activity helped me understand the different components of cloud infrastructure and how they work together. I think the compute resource is one of the most important components because it performs the processing needed by applications and services. It allows users and organizations to run workloads in the cloud without depending entirely on physical computers. However, compute resources still need networking and storage to work effectively and provide complete cloud services.

Linux also plays an important role in cloud computing because it provides a reliable operating system for many servers and cloud environments. It gives users and administrators command-line tools for monitoring and managing system resources. During this laboratory, Linux commands helped me examine information about the server's CPU, memory, storage, network, and operating system. This experience helped me understand how Linux can be used to manage and monitor cloud-based infrastructure.

Technical documentation is also important before deploying infrastructure because it provides a clear plan of the system. It records the components, configurations, commands, and other important information needed for the deployment. Good documentation can help reduce errors, make troubleshooting easier, and allow team members to understand how the infrastructure is organized. It also provides a useful reference when changes or maintenance are needed.

Throughout this laboratory activity, I learned how to use Linux commands to investigate a cloud-based server and identify its available resources. I also practiced creating Markdown tables and organizing technical information properly. Another skill I developed was comparing equivalent services offered by AWS, Microsoft Azure, and Google Cloud. I also learned how to create a simple cloud infrastructure diagram and organize project files using Git and GitHub.

Overall, my GitHub portfolio became more organized and informative after completing this laboratory. I added technical documentation, cloud infrastructure information, a cloud provider comparison, and a cloud architecture diagram. I also practiced using Git commands for committing and pushing my work. These improvements make my portfolio a better record of my cloud computing skills and the knowledge I gained from this laboratory activity.
