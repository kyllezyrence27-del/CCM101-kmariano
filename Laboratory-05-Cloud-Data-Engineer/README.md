## Mission Overview

In this laboratory activity, I explored the different types of cloud storage and learned how object storage is used to store and manage large amounts of data. I used Docker to deploy MinIO, an S3-compatible object storage server, and accessed its web console to create a storage bucket and upload a sample file.

This activity helped me understand how cloud storage works and how containerization makes deploying cloud services easier and more manageable.

## Mission Objectives

The objectives of this laboratory activity are:

1. Differentiate Block Storage, File Storage, and Object Storage.
2. Deploy a MinIO object storage server using Docker.
3. Access a cloud service through a web browser using port forwarding.
4. Create a storage bucket named `client-photos`.
5. Upload a sample file to the object storage server.
6. Document the deployment process and technical configurations using Markdown.
