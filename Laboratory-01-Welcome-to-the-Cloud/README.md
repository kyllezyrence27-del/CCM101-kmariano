# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the basic concepts and practical skills needed to work in a Linux cloud environment. The activity focuses on using KillerCoda, exploring Linux, gathering system information, organizing files, and creating a professional GitHub portfolio.

## Objectives

- Access and use a cloud-based Linux environment.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

- Accessed the Ubuntu Linux environment through KillerCoda.
- Created and logged in to the `acabading` user account.
- Checked the username, working directory, and hostname.
- Investigated the Linux distribution, kernel, CPU, memory, and disk space.
- Created and organized the required directories and Markdown files.
- Prepared the Cloud Computing portfolio repository on GitHub.

## Linux Commands Used

- `adduser` – creates a new user.
- `usermod` – modifies user account settings.
- `su` – switches to another user.
- `whoami` – displays the current username.
- `pwd` – displays the current working directory.
- `hostname` – displays the system hostname.
- `cat` – displays file contents.
- `uname -r` – displays the kernel version.
- `lscpu` – displays CPU information.
- `free -h` – displays memory information.
- `df -h` – displays disk space information.
- `mkdir` – creates directories.
- `cd` – changes the current directory.
- `nano` – creates and edits text files.
- `cp` – copies files and directories.
- `ls` – lists files and directories.
- `git` – manages version control.

## Skills Learned

Through this activity, I learned how to access and work with a cloud-based Linux environment, use basic Linux commands, gather system information, organize files and directories, create Markdown documentation, and prepare a GitHub portfolio for cloud computing laboratory activities.
