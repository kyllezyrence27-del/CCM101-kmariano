# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers cloud services for computing, storage, databases, networking, data analytics, artificial intelligence, machine learning, and application development.

## Global Infrastructure

GCP operates through a global infrastructure made up of regions and zones. A region represents a geographic location, while zones are isolated deployment areas within a region. This structure helps organizations deploy applications across different locations and improve availability.

## Cloud Management Console

The Google Cloud Console is a web-based interface for managing Google Cloud resources. It allows users to create and configure services, monitor resources, manage access and permissions, and view project information from a centralized dashboard.

## Four Core Services

1. **Compute Engine** – Provides virtual machines that can run Linux, Windows, and other operating systems for different workloads.
2. **Cloud Storage** – Provides scalable object storage for files, backups, media, datasets, and application data.
3. **Cloud SQL** – Provides a managed relational database service that supports database engines such as MySQL, PostgreSQL, and SQL Server.
4. **Google Kubernetes Engine (GKE)** – A managed Kubernetes service used to deploy, manage, and scale containerized applications.

## Three Advantages

1. **Data and Analytics Capabilities** – GCP provides powerful services for processing, analyzing, and managing large amounts of data.
2. **Artificial Intelligence and Machine Learning** – Google Cloud offers tools and services that support AI and machine learning development.
3. **Scalable Infrastructure** – Cloud resources can be adjusted according to application workloads and organizational requirements.

## Typical Enterprise Use Cases

Organizations can use GCP for hosting applications, running virtual machines, storing business data, managing relational databases, analyzing large datasets, deploying containerized applications, and developing artificial intelligence and machine learning solutions.
