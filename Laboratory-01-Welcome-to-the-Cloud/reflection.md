# Reflection

This laboratory activity helped me understand how to work in a Linux cloud environment and how cloud engineers organize and document their work. I learned how to create a user, navigate directories, check system information, create Markdown files, and prepare a GitHub repository.

One problem I encountered was with the KillerCoda Playground. When I did not return to the playground for a long time, the environment could disconnect or reset, causing some of the commands and files I had created to disappear. Sometimes the playground also returned to the beginning, so I had to repeat some steps. This taught me the importance of saving my work, documenting each step, and regularly pushing files to GitHub.

I also encountered some difficulties while learning Git, especially when configuring my Git username and email and connecting the local repository to GitHub. These challenges helped me understand that version control requires careful configuration.

Overall, this activity improved my confidence in using Linux, Git, GitHub, and Markdown. I learned that proper documentation and regular backups are important when working with cloud environments.
