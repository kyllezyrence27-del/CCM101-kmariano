# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Introduction

This laboratory activity introduces the basic structure of cloud infrastructure. It explores how computing resources, storage, networking, and user identity services are connected to support cloud-based systems.

## Learning Goals

After completing this laboratory, the learner should be able to:

* Identify the essential parts of a cloud infrastructure.
* Examine the available resources of a Linux-based cloud server.
* Describe the roles of compute, storage, networking, and identity services.
* Compare infrastructure services from major cloud providers.
* Create a basic cloud infrastructure design.
* Document technical findings using Markdown.
* Organize and improve a GitHub Cloud Computing portfolio.

## Mission Checkpoints

The laboratory consists of seven major checkpoints:

1. Expand the Cloud Portfolio
2. Investigate the Cloud Server
3. Identify Cloud Infrastructure Components
4. Research Major Cloud Providers
5. Design a Simple Cloud Infrastructure
6. Complete the Technical Documentation
7. Write the Mission Reflection

## Resources and Tools

The following resources will be used throughout the activity:

* KillerCoda Playground
* Ubuntu Linux environment
* Git and GitHub
* Markdown
* Official cloud provider documentation
* Cloud architecture diagramming tools

## Expected Output

The completed laboratory will contain technical reports, cloud infrastructure comparisons, a simple architecture diagram, screenshots, and a reflection documenting the learning experience.

## Cloud Infrastructure Components

- **Compute:** Provides processing power for applications and workloads.
- **Storage:** Stores files, data, and other digital resources.
- **Network:** Connects users, compute resources, and storage resources.
- **User:** Represents the person accessing the cloud infrastructure.
- **Internet Connection:** Provides external connectivity to the cloud environment.
