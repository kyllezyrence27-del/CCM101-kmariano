# Reflection

## Laboratory 04: Cloud-Native Engineer

This laboratory activity helped me understand the importance of containers in modern cloud computing. Before doing this activity, I only had a basic idea about Docker and how it is used. Through the different tasks, I learned that containers allow applications and their dependencies to run in an isolated and consistent environment.

One of the most important things I learned was the difference between virtualization and containerization. Virtual machines require a complete operating system for each environment, while containers share the host operating system kernel. Because of this, containers are generally faster to start and use fewer resources. This makes them useful for application development, testing, and deployment.

I also learned how to use basic Docker commands such as `docker --version`, `docker info`, `docker pull`, `docker run`, `docker ps`, `docker stop`, and `docker start`. Running an Nginx container helped me understand how an application can be downloaded, started, accessed through a port, stopped, and started again. The container lifecycle showed me that managing applications involves more than simply running a command.

One challenge I experienced was remembering the purpose of each Docker command and understanding how containers work in the background. I overcame this by following the laboratory instructions carefully and observing the results of every command. The activity also taught me the importance of documentation and screenshots as evidence of completed tasks.

Overall, this laboratory improved my understanding of cloud-native technologies and container management. I learned that Docker can make application deployment more efficient, portable, and organized. I believe the knowledge I gained from this activity will be useful in future cloud computing projects and in my preparation for a career in information technology.
