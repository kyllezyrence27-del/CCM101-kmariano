# Laboratory 06 – Cloud Deployment Engineer

**Name:** Kylle Zyrence Mariano  
**Program:** Bachelor of Science in Information Technology  
**Course:** CCM101 – Cloud Computing

## Mission Overview

This laboratory introduces the deployment of a multi-container cloud application using Docker Compose. The project uses Nextcloud as the web application and MariaDB as its database service.

## Objectives

- Explain the purpose of a multi-tier application.
- Create a Docker Compose configuration file.
- Deploy and manage interconnected containers.
- Configure communication between an application and database service.
- Record and document the deployment process.

## Laboratory Checkpoints

- Checkpoint 1 – Expand Your Cloud Portfolio
- Checkpoint 2 – Multi-Tier Architecture Research
- Checkpoint 3 – Infrastructure Code
- Checkpoint 4 – Multi-Container Deployment
- Checkpoint 5 – Private Cloud Access
- Checkpoint 6 – Technical Documentation
- Checkpoint 7 – Mission Reflection

## Skills Learned

This activity provides hands-on experience with Docker Compose, containerized applications, database services, multi-tier architecture, and cloud infrastructure management.
