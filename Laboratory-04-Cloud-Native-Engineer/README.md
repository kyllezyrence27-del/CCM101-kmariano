# Laboratory Activity 4: Cloud-Native Engineer

## Mission Overview

This laboratory activity introduces the concept of cloud-native engineering and container technology. It focuses on the comparison between traditional Virtual Machines (VMs) and Containers and demonstrates how Docker can be used to deploy applications in a Linux environment.

The main purpose of this activity is to understand how modern applications can be packaged and managed using containers. Through practical exercises, I was able to explore Docker commands, run an Nginx web server, and perform different container management operations.

## Objectives

The objectives of this laboratory activity are to:

- Identify the differences between Virtual Machines and Containers.
- Learn the basic principles of containerization.
- Use Docker commands through the Command Line Interface.
- Run and verify a containerized Nginx web server.
- Perform basic container lifecycle management.
- Create clear and organized technical documentation.
- Continue developing a professional GitHub Cloud Computing portfolio.

## Docker Commands Executed

During the laboratory activity, I used the following Docker commands:

- docker --version
- docker info
- docker pull nginx
- docker run
- curl http://localhost:8080
- docker ps
- docker stop
- docker start
- docker rm

## Skills Learned

I gained a better understanding of how container technology works and why it is useful in cloud computing. I learned how Docker images and containers are related and how commands can be used to control running applications.

The activity also improved my ability to document technical procedures and organize project files properly using GitHub.

## Challenges Encountered

One of the challenges I experienced was becoming familiar with Docker commands and their functions. Some commands are used for creating containers while others are used for monitoring or removing them.

I also needed to ensure that every required file and screenshot was placed in the correct folder. Reviewing the instructions carefully helped me complete the activity in an organized manner.
