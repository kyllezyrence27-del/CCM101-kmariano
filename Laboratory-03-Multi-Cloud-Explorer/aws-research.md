# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of services for computing, storage, databases, networking, security, and other IT needs. It allows organizations to use cloud resources without having to maintain all of the physical infrastructure themselves.

## Global Infrastructure

AWS operates through a global infrastructure made up of Regions and Availability Zones. Regions are separate geographic areas, while Availability Zones are isolated locations within a Region that help applications remain available and resilient.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create resources, configure services, monitor their cloud environment, and manage security settings through the console.

## Four Core Services

1. **Amazon EC2** – Provides virtual servers for running applications and workloads.
2. **Amazon S3** – Provides scalable object storage for files and other data.
3. **Amazon RDS** – Provides managed relational database services.
4. **Amazon VPC** – Allows users to create and manage isolated virtual networks in AWS.

## Three Advantages

1. AWS provides a large selection of cloud services for different technical requirements.
2. Its global infrastructure supports scalable and highly available applications.
3. AWS uses a flexible pricing model that allows organizations to pay for the resources they use.

## Typical Enterprise Use Cases

AWS can be used by enterprises for hosting websites and applications, storing and processing large amounts of data, running databases, creating backup systems, and supporting artificial intelligence and machine learning workloads.
